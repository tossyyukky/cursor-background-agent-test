# 📝 Modern TODO App

美しく、モダンなTODOアプリケーションです。React.jsとViteを使用して構築されています。

## ✨ 機能

- ✅ タスクの追加・編集・削除
- 🎯 タスクの完了状態の切り替え
- 📊 進捗バーによる視覚的な進捗表示
- 🌙 ダークモード対応
- 💾 ローカルストレージによるデータ永続化
- 📱 レスポンシブデザイン
- 🎨 美しいアニメーションとグラデーション

## 🚀 使用方法

### 開発環境の起動

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

### 本番環境向けビルド

```bash
# 本番環境向けビルド
npm run build

# ビルド結果のプレビュー
npm run preview
```

### シンプルなサーバーでの起動

```bash
# Pythonを使用したシンプルなサーバー
npm run serve
```

## 📱 機能詳細

### タスク管理
- **追加**: 入力フィールドにタスクを入力してEnterキーまたは「+」ボタンで追加
- **編集**: タスクをクリックまたは編集ボタンでインライン編集
- **完了**: チェックボックスをクリックで完了状態を切り替え
- **削除**: 削除ボタンでタスクを削除

### UI機能
- **ダークモード**: 右上の月/太陽アイコンで切り替え
- **進捗表示**: 完了したタスクの割合をプログレスバーで表示
- **レスポンシブ**: スマートフォンからデスクトップまで対応

## 🌟 特徴的な機能

1. **自動保存**: タスクの変更は自動的にローカルストレージに保存
2. **キーボードショートカット**: 
   - Enter: 新しいタスクの追加
   - Enter（編集中）: 編集の保存
   - Escape（編集中）: 編集のキャンセル
3. **美しいアニメーション**: ホバー時やフォーカス時の滑らかな変化
4. **インライン編集**: タスクをダブルクリックで即座に編集開始

## 🔧 カスタマイズ

色やスタイルをカスタマイズする場合は、`src/App.css`を編集してください。CSS変数を使用して簡単にテーマを変更できます。
